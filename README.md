# Генеалогическое дерево

Откройте `index.html` в браузере. Интернет и отдельный сервер не нужны; папки `web` и `photos` должны оставаться рядом с файлом.

Для локального редактора и обновления HTML нужны Python 3.10+, Node.js и Pillow: `python3 -m pip install -r requirements.txt`. Все библиотеки браузерной части уже находятся в `web/vendor`; установка npm-пакетов не требуется. Команда запуска сначала использует окружение `.venv`, затем готовое окружение Codex, иначе — `python3` из PATH.

В Git хранятся только код, схема и синтетический пример в `examples/`. Настоящие семейные записи, фото, исходные материалы, миниатюры, временные проверки, резервные копии и PDF исключены через `.gitignore` и остаются локальными. Новый PDF можно скачать кнопкой **Pobierz PDF**. Чистая копия репозитория открывает демонстрационное дерево без фотографий; локальный редактор создаёт отдельные файлы примера только при отсутствии обоих файлов данных. Существующие записи не заменяются.

## Редактирование

В карточке человека нажмите **Edit**. Можно изменить имена, фамилии, даты и их приблизительные описания, статус жизни, места рождения и смерти, родителей, родство, браки, источники, примечания и фото. Постоянный ID не изменяется. Даты можно вводить с точностью до года, месяца или дня: `1968`, `1968-05`, `1968-05-21`. Год синхронизируется с датой.

Есть два режима сохранения; текущий режим указан над деревом:

- **В папку проекта:** дважды нажмите `Uruchom edytor.command` в Finder. Откроется локальный редактор в браузере. Кнопка **Zapisz** обновляет `family-tree.json`, `family-tree-review.json`, данные HTML и сохраняет новое фото в `photos/`. Перед сохранением создаётся копия исходных JSON в `backups/editor/`. Оригинал загруженного фото сохраняется без изменений. Удаление его привязки не удаляет старый файл. Чтобы остановить редактор, нажмите Ctrl+C в открытом окне Terminal.
- **Обычный HTML:** изменения сохраняются в этой браузерной программе и остаются после перезагрузки. Чтобы перенести их в папку проекта, нажмите **Pobierz zmiany (.zip)** и распакуйте архив в прежнюю папку проекта с заменой файлов. Архив содержит данные, новые фото и обновлённый снимок HTML. Этот режим сам не изменяет исходные файлы проекта. Если данные проекта были обновлены отдельно, старые браузерные правки не накладываются автоматически; их можно скачать отдельной кнопкой.

Встроенные проверки отклоняют неверные даты, циклы родства и одновременное указание живого человека и даты его смерти. Неизвестные связи можно оставить пустыми; потеря установленного соединения с основным человеком дерева явно отмечается в карточке. При одновременной правке одной записи из двух окон редактор просит обновить устаревшее окно.

**Обозначения дат:** `?` — неизвестно; `...` вместо даты смерти — человек подтверждённо жив. Отсутствие даты смерти не меняет неизвестный статус жизни на «жив». Приблизительные сведения сохраняются в скобках, например `? (przed 1917)`.

- Нажмите на человека, чтобы открыть его сведения, семейные связи, источники и вопросы, требующие уточнения.
- Нажмите на фото в карточке, чтобы увеличить его. По родственникам в карточке можно переходить дальше.
- Перетаскивайте дерево, используйте поиск, кнопки масштаба, «имя основного человека» и «Całe drzewo».
- Зажмите левую кнопку мыши на карточке и двигайте её влево или вправо. Поколение остаётся прежним, соседние карточки сдвигаются, а линии родства следуют за карточками. Для перемещения всего дерева перетаскивайте пустое место. На сенсорном экране перетаскивание продолжает перемещать всё дерево.
- **Cofnij** / Ctrl+Z (на Mac ⌘Z) отменяет перемещение; **Ponów** / Ctrl+Shift+Z повторяет его. **Esc** отменяет ещё не завершённое перетаскивание. **Układ początkowy** возвращает автоматическое расположение; этот сброс тоже можно отменить. История отмены хранится в текущем сеансе страницы.
- Переключатель **Przesuwanie kart** выключает функцию перетаскивания карточек. Ручное расположение сохраняется в этом браузере для этого адреса страницы отдельно от сведений о родственниках; после перезагрузки его можно полностью сбросить кнопкой **Układ początkowy**. При изменении родственных связей и перестроении поколений используется новая автоматическая расстановка.
- «Pobierz PDF» создаёт и скачивает PDF всего дерева из данных страницы, независимо от текущего масштаба и выбранного человека. Формат — A0, горизонтально. Фотографии и польские подписи сохраняются; это графический рендер.

Экспорт PDF использует текущее расположение карточек. Архив изменений сохраняет семейные сведения и фотографии; ручная расстановка остаётся настройкой этого браузера. До добавления перетаскивания исходные файлы интерфейса сохранены в `backups/ui-before-card-drag-20261124-124702/` с инструкцией полного отката.

Основные данные хранятся в `family-tree.json`. HTML использует подготовленный снимок этих данных в `web/family-data.js`. После изменения данных обновить страницу командой:

```sh
python3 scripts/build_html.py
```

Эта команда обновляет только данные HTML и расположение людей; PDF не создаёт. Перезагрузите открытую страницу, чтобы увидеть изменения. Фотографии в `photos` при подготовке страницы не изменяются.

Последний отдельно подготовленный рендер: `output/pdf/family-tree-preview-v3.pdf`.

Страница работает локально и не обращается к внешним сервисам. Внешние источники открываются только по нажатию на ссылки. Для экспорта PDF используется библиотека pdf-lib; её лицензия находится в `web/vendor/pdf-lib-LICENSE.md`.

Локальный режим редактора обращается только к серверу на этом компьютере. Для архива изменений используется JSZip, для перестройки дерева при офлайн-правках родства — Viz.js. Библиотеки находятся в `web/vendor` и работают без интернета.

Проверка сохранения и валидации на отдельной копии данных:

```sh
python3 tests/test_editor.py
```

Проверка горизонтального размещения и привязки линий:

```sh
node tests/test_card_layout.cjs
```
