# Инструкции для рабочих сессий проекта

Перед изменениями прочитайте [rules.md](rules.md), [sdlc.md](sdlc.md) и нужные разделы [deploy.md](deploy.md). Они хранят согласованные решения и контекст независимо от истории чата.

Перед проектированием, изменением или проверкой интерфейса все агенты обязаны прочитать и соблюдать [design-rules.md](design-rules.md). Этот файл содержит общие правила дизайна и целевые требования мобильной версии; статус реализации проверяйте в `sdlc.md`.

Ключевые ограничения: гостевой режим только для чтения, семейный вход — клиентский прототип без серверной записи; настоящие семейные данные и фото не входят в Git; неоднозначные семейные сведения подтверждает пользователь; групповые портреты назначаются после одобрения обычной обрезки без ИИ; PDF не пересоздаётся при каждом обновлении.

Сохраняйте существующие локальные данные и незакоммиченные изменения. Не включайте в коммиты игнорируемые материалы. Push в `main` запускает production-деплой. Изменения подтверждённого статуса и договорённостей отражайте в документах проекта.
