# Регрессионные тест-кейсы сайта

Актуализировано: 27.11.2026, qa-tester. Эталон — поведение рабочей копии на эту дату (решение владельца: свет­лая карточка подсвечивает линию родства, тёмная открывает сведения).

Цель набора — чтобы будущая разработка и код-ревью не сломали то, что сейчас работает так, как хочет владелец. Каждый кейс имеет ID; автотесты называются по тем же ID (`test_TC_…`).

## Как пользоваться

| Когда | Что запустить |
|---|---|
| Перед коммитом и на код-ревью любой задачи | `sh tests/run_all.sh` — все автотесты (≈1–2 мин) |
| Перед выпуском и после деплоя | ручные кейсы раздела «Только вручную» по затронутой области + смоук production (M-PROD) |
| Автоматически | GitHub Actions перед каждым деплоем: при любом упавшем тесте публикации нет |

Подготовка один раз на Mac: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt playwright`. Браузерные тесты используют установленный Google Chrome; если его нет — `.venv/bin/python -m playwright install chromium`. Окно браузера можно увидеть: `E2E_HEADED=1 .venv/bin/python tests/test_e2e.py`. Синтетический сайт для ручной проверки: `.venv/bin/python tests/e2e_site.py` → <http://127.0.0.1:8765>.

Все тесты работают только на синтетических данных (`tests/fixtures/e2e/`, `examples/`). Настоящие семейные данные, фото и аккаунты в тесты не попадают.

### Правила поддержки
1. Задача, меняющая поведение, в том же изменении обновляет затронутые кейсы здесь и соответствующие тесты. Ревьюер проверяет, что тест изменён осознанно, а не ослаблен ради зелёного прогона.
2. Удалять или ослаблять тест без поручения владельца нельзя. Упавший тест = регрессия, пока не доказано обратное.
3. Эталон раскладки `tests/golden/e2e-layout.json` обновляется только при согласованном изменении геометрии: `UPDATE_GOLDEN=1 node tests/test_layout_golden.cjs`, разница показывается в задаче.
4. Новый дефект → сначала тест, воспроизводящий его, потом исправление.
5. Ручные проверки фиксируются в задаче и в `sdlc.md` со средой, шириной, языком и режимом; непроверенное указывается явно.

Обозначения: **E2E** — `tests/test_e2e.py` (Chrome), **U** — Node/Python-тест, **M** — вручную. Среды по умолчанию: десктоп 1280×800, гость, польский.
